"Load data/ folder…" reads every CSV in your local data/ directory at once (nothing leaves your browser) — every genre's files load together, so switching the Genre selector above never needs a reload. Each tab shows only the selected genre's file(s) (a tab with no per-genre split, like Psychic, is unaffected by this selector). Each section has its own Save button, which writes 3 files, in order: 2 backup copies of the file exactly as it was before you loaded it (name.bak1.csv / name.bak2.csv), then the actual updated file. "Enable direct save to data/…" lets you grant this page write access to your data/ folder (a one-time browser permission prompt) so Save writes all 3 files straight there — no manual moving. If your browser doesn't support that (or you skip it — Safari and Firefox never offer it, only Chrome/Edge/Brave/Opera do), Save falls back to 3 ordinary downloads instead — move the backups into your backup directory and the real file into data/, replacing the original, by hand. "Save All" saves every changed file across every genre and tab in one click: with direct save enabled it just writes them all straight to disk; otherwise, instead of a pile of separate downloads, it bundles every changed file (plus its 2 backups) into one vg-tools-save-all.zip with a data/ folder and a backups/ folder inside, ready to drop into place. The Magic/Cyber/Mutant/Psychic toggles above show and hide that system's tab for the selected genre, and reflect/edit that genre's row(s) in tech_levels.csv — flip one and use "Save tech_levels.csv" (or "Save All") to write that change to disk. None of the above reaches the character builder on its own — Save/Save All only persist your own CSV editing session. "Publish Game Set" is the separate, deliberate step that does: it bundles everything currently loaded (every genre, every tab, tech_levels.csv, and the current genre list — even a genre created or discovered this session) into one gameset.json, written or downloaded the same way as any other save. The character builder loads whatever gameset.json it can fetch at startup, so a genre or change doesn't reach players until you click Publish — you can keep editing/saving privately without it showing up for anyone until you're ready.
